# Classic Robocode sounds

`zap.wav` (gunshot), `shellhit.wav` (a bullet hits a robot or a bullet), `explode.wav` (a robot dies) and `13831_adcbicycle_22.wav` (a robot hits a robot or a wall) are the default sound effects of classic Robocode 1.11.1 (`robocode.sound`, `net/sf/robocode/sound/sounds/`), unmodified. The GUI plays them as classic's `SoundManager` does (`src/sound.rs`).
