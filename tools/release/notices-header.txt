4. Java runtime (not included)
------------------------------

Robots run on a Java runtime, which is not part of this archive: on first use
robocode-s downloads Eclipse Temurin 21 (a JRE), checks its SHA-256 and keeps it
in its data folder. Eclipse Temurin is licensed under the GNU General Public
License, version 2, with the Classpath Exception (https://adoptium.net/). With
`--sandbox docker` the official eclipse-temurin image is pulled instead.
