# 0008. EPL-2.0 license; classic samples bundled under EPL-2.0

- Status: Accepted
- Date: 2026-10-10

## Context

Classic Robocode is EPL-1.0. We want the option to port code from it, and we want its sample robots as test corpus and examples.

## Decision

robocode-s is licensed under EPL-2.0. The 27 classic sample robots are bundled with their original copyright and a header noting the move from EPL-1.0 to EPL-2.0 under section 7 of EPL-1.0 (design §13.1).

## Consequences

Code ported from classic Robocode keeps its copyright notice.
