robocode-s is a reimplementation of [Robocode](https://robocode.sourceforge.io/), the programming game where you write the brain of a tank and let it fight. These pages are for **robot authors**: people who write bots, test them and enter them in the rumble.

- **[About robocode-s](/docs/about)**: what it is, how it relates to classic Robocode and Tank Royale, and where the project stands.
- **[Getting started](/docs/getting-started)**: what you can do today, and what installing will look like.
- **[Developing a robot](/docs/robot-development)**: how to set up a robot project, test it, debug it and release it.
- **[The rumble](/docs/rumble)**: divisions, weight classes, how scores are computed, and how battles are run and checked.

> **Status:** robocode-s is in early development and has no release yet. Pages mark what already works and what is planned. If something here is unclear or wrong, [open an issue](https://github.com/nhofsted/robocode-s/issues).

Building robocode-s itself, the protocol and the engine internals are documented in the repository: the [design document](https://github.com/nhofsted/robocode-s/blob/main/docs/design.md), the [engine specification](https://github.com/nhofsted/robocode-s/blob/main/docs/engine-spec.md) and the [architecture decision records](https://github.com/nhofsted/robocode-s/blob/main/docs/adr/README.md).
