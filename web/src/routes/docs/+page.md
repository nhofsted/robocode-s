---

robocode-s is a reimplementation of [Robocode](https://robocode.sourceforge.io/), the programming game where you write the brain of a tank and let it fight. These pages are for **robot authors**: people who write bots, test them and enter them in the rumble.

- **[Getting started](/docs/getting-started)**: install, run a battle, write a robot.
- **[Developing a robot](/docs/robot-development)**: how to set up a robot project, test it, debug it and release it.
- **[Using an IDE](/docs/ide)**: set up IntelliJ IDEA, Eclipse or VS Code, Gradle or Maven, and test in robocode-s.
- **[Command line](/docs/cli)**: `battle`, `replay`, `ide-config`, `agent` and `rumble`, with every option.
- **[The rumble](/docs/rumble)**: divisions, weight classes, how scores are computed, how battles are run and checked, and how to [contribute battles](/docs/rumble/contributing).
- **[About robocode-s](/docs/about)**: what it is, how it relates to classic Robocode and Tank Royale, and where the project stands.
- **[Community and links](/docs/community)**: the RoboWiki, LiteRumble, the Google Group, Facebook and Reddit: where the Robocode community learns, competes and talks.

> **Status:** robocode-s is in development. Version 0.2.0 is out for Windows, Linux and macOS ([download](/download)), with the rumble client. Pages mark what already works and what is planned. If something here is unclear or wrong, [open an issue](https://github.com/nhofsted/robocode-s/issues).

Building robocode-s itself is on the [download page](/download/source). The engine internals are documented in the repository: the [engine specification](https://github.com/nhofsted/robocode-s/blob/main/docs/engine-spec.md) and the [architecture decision records](https://github.com/nhofsted/robocode-s/blob/main/docs/adr/README.md).
