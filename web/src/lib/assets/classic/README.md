# Classic Robocode images

`body.png`, `turret.png`, `radar.png` and `explosion/explosion1-*.png` are the robot and bullet-explosion images of classic Robocode 1.11.1 (`robocode.ui`, `net/sf/robocode/ui/images/`), unmodified.

They are recoloured in the browser with classic's own algorithm (`ImageUtil.ColorFilter`), ported in `../../components/sprites.ts`.

`static/favicon.png` is the logo tank (these sprites in the logo colours), rendered by the site itself.
